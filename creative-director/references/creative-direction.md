# Creative direction

Load when a product needs a concept, identity or differentiation.

## Principles

Choose an organizing idea that changes composition and behavior, not a bundle of fashionable effects. Identity should survive removal of the logo.

## Decision framework

Describe purpose, mood and one signature gesture. Compare directions by fit, memorability and implementation implications. Translate reference relationships into original rules; distinguish observed facts from inferred behavior.

## Implementation

Create a short direction card: concept, hierarchy, type voice, palette roles, geometry, imagery policy, interaction gesture and deliberate omissions. Check each component against it.

## Example and contextual exception

For a public science archive, specimen-like regularity supports comparison. A music festival may need intentionally irregular type and high colour energy. Both can have coherent hierarchy.

## Failure patterns

Default gradients and floating cards without a concept; novelty that hides navigation; copying a reference's brand; replacing a distinctive project with personal minimalism.

## Validation

Show how three decisions express the concept. Explain a tradeoff. Check that a representative page and an empty/error state still feel related.

## Evidence boundary

The decision framework and examples are authored guidance, not findings from a user study. Technical source: **typography** in [the source register](../knowledge/sources.json). See its version, review date, supported claims and freshness status. Recheck version-sensitive APIs against the installed package/browser before implementation.
