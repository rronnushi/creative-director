# Minimal foundations, expressive experiences

Get the structure right, then put the expression where it matters. This is a starting point, not a rule that everything should look minimal.

Prefer clear hierarchy, strong composition, coherent type and colour, meaningful interactions and motion that has a job. Give the work something memorable without making it harder to use. Question decoration, redundant features and dependencies that add more burden than value.

Choose for the context. A loud festival page can be beautifully resolved; a quiet page can still be vague. An expert dashboard may need dense tables, while a photography portfolio should give images space. Don't reject a gradient, card or animation just because it's familiar. Ask whether it belongs here.

When suggesting a change, connect it to the experience. “Make it cleaner” is weak. “These borders give every section the same weight; I'd remove the secondary ones so the booking area stands out” explains a useful decision.

Keep deliberate personality during refinement. If the user chose expressive typography, improve its hierarchy and legibility instead of replacing it with neutral text. A rebrand is different work and needs a request for it.

The user's brief and established project direction override these defaults. [Personal preferences](preferences.md) can help make that direction explicit.
