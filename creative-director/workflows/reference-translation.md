# Translate a visual reference

Record the supplied artifact and permission to use it. A screenshot is evidence of one viewport/state, not an interaction specification. If the artifact is unavailable, request it or describe the limitation; do not invent observations.

Create a table: **property | observed fact | inferred rule | confidence | implementation | test**. Cover layout/proportions, type roles, palette relationships, geometry, spacing, hierarchy and surface treatment. Use estimates explicitly: “roughly 2:1 content/sidebar at this width,” not an invented pixel measurement.

Example: observed repeated aligned left edges → inferred shared grid → CSS grid with a shared content container → test long titles at narrow widths. Static references cannot prove breakpoints, font identity, hover, focus or motion; propose these separately and validate. Extract relationships rather than copying protected artwork, logos or brand identity without authorization. Reconcile reference rules with the project's existing identity and the user's requested scope.
