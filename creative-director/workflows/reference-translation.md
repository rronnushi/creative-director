# Work from a visual reference

Look at the supplied image or page before describing it. If it isn't available, ask for the missing artifact or explain the limit.

Identify the relationships worth carrying over: grid, proportions, hierarchy, type roles, colour relationships, spacing, geometry and surface treatment. Separate visible facts from your interpretation.

For example: “The image takes about two thirds of this layout. I'd keep that image-led balance, but use our existing type and colours.” If a measurement is approximate, say so.

A static reference doesn't reveal hover, focus, motion or breakpoints. Suggest those separately instead of presenting them as observations. Test the proposed rules with long content and different screen sizes.

Translate the reference into a few practical layout and styling rules. Adapt them to the user's own identity; don't copy branding or artwork without permission. Use a detailed property table only when the handoff needs one.
