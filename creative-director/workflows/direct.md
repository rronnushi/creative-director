# DIRECT

Use when direction is the requested deliverable. Read product thinking for ambiguous value and creative direction for identity decisions.

1. Frame the audience, situation, main task, emotional character, constraints and success signal. Separate known facts from assumptions.
2. For an open brief, compare two or three materially different concepts: their organizing idea, composition, interaction and cost. A font swap is not a new concept. For an already chosen direction, develop it directly.
3. Recommend a direction with a reason tied to audience and task. Describe what the experience should make easy and what it should make memorable.
4. Translate adjectives into rules: type roles, content hierarchy, spacing rhythm, colour roles, component geometry, motion purpose and responsive adaptations. Include one thing to avoid and a contextual exception.
5. Provide a small first prototype or validation experiment as a next step, without implementing unless requested.

Output contract: brief → alternatives/tradeoffs when useful → selected concept → actionable rules → technical implications → open assumptions. Example: for an archive, “specimen cabinet” means equal artwork frames, metadata beside rather than over images, immediate filters, and a viewer that retains filter state on return. A loud event campaign could instead make typography the main image.
